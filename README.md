# 📈 News2Market
### AI-Powered Financial News & Market Analysis Platform

News2Market is a full-stack platform that explores the relationship between financial news and stock market movements using Natural Language Processing (NLP), Machine Learning (ML), and financial data analysis.

The platform aims to combine financial news sentiment with historical market data to generate meaningful insights into market trends and stock price movements.

## 🎯 Key Objectives

- Integrate financial news with stock market data.
- Analyze financial news sentiment using NLP.
- Explore relationships between sentiment and stock price movements.
- Apply machine learning to financial data analysis and prediction experiments.
- Present insights through interactive dashboards and visualizations.

## ✨ Key Features

- **Financial News Aggregation:** Browse and filter news by company, category, and date.
- **Stock Market Analysis:** Explore stock information, historical prices, and market trends.
- **Sentiment Analysis:** Classify news as positive, negative, or neutral.
- **News–Market Relationship Analysis:** Compare news sentiment with stock price movements.
- **Machine Learning:** Perform feature engineering, model training, evaluation, and prediction experiments.
- **Interactive Dashboard:** Visualize market indicators, sentiment scores, price trends, and analytical insights.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- Python 3.10+
- PostgreSQL
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/news2market.git
cd news2market
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal by Vite.

### 3. Backend Setup

Open a new terminal from the project root:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment.

**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

Install dependencies and start the API:

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- Backend API: `http://127.0.0.1:8000`
- Interactive API documentation: `http://127.0.0.1:8000/docs`

### 4. Machine Learning Setup

Open another terminal from the project root:

```bash
cd ml
python -m venv venv
```

Activate the environment.

**Windows:**
```bash
venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

Install ML dependencies:

```bash
pip install -r requirements.txt
```

The ML environment will be used for data preprocessing, sentiment analysis, feature engineering, model training, and evaluation.

### 5. Environment Variables

Create `.env` files in the relevant directories using the corresponding `.env.example` files as templates.

**Backend environment variables:**

```env
DATABASE_URL=postgresql://username:password@localhost:5432/news2market
NEWS_API_KEY=your_news_api_key
MARKET_API_KEY=your_market_api_key
```

**Frontend environment variable:**

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

**Important:**
- Replace placeholder values with your actual configuration.
- Create the PostgreSQL database before connecting the backend.
- Configure API keys according to the selected news and market data providers.
- Never commit `.env` files, API keys, passwords, or other secrets to GitHub.
- Commit `.env.example` files containing placeholders instead.
